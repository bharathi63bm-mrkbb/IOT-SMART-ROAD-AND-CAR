# IoT-Based Smart Road Management System

## 📌 Project Overview

The **IoT-Based Smart Road Management System** is an IoT project designed to improve road safety, traffic management, parking, street lighting, and emergency vehicle priority.

The system uses **ESP32, sensors, traffic signals, IoT dashboard, and a phone-controlled car** to demonstrate smart road management.

## 🚦 Main Features

### 1. Phone-Controlled Car

* Control the car using a mobile phone.
* ESP32 controls the movement of the car.
* Speed and fan can also be controlled.
* http://192.168.4.1/ Using this wee Control Car in anywhere with Wi-Fi connection.

### 2. Smart Traffic Signal

* Controls traffic signals automatically.
* Helps manage vehicle movement.
* Improves traffic safety.

### 3. Pedestrian Crossing

* Pedestrians can request road crossing using buttons.
* Buzzer provides an alert while crossing.
* Vehicle movement is controlled for safety.

### 4. Smart Parking

* IR sensors detect available parking slots.
* The parking status is displayed to users.
* Users can monitor parking availability remotely.

### 5. Smart Street Lighting

* LDR detects day and night conditions.
* Vehicle detection controls the street lights.
* Helps reduce unnecessary power consumption.

### 6. Ambulance Priority

* A sound sensor detects an ambulance siren.
* The system gives priority to the ambulance.
* The required traffic signal is changed to green.

### 7. IoT Monitoring

* The system can be monitored using an IoT dashboard.
* Important road and parking information can be viewed remotely.

## ⚙️ Working

The ESP32 acts as the main controller of the system. Sensors collect information about vehicles, parking slots, pedestrians, lighting conditions, and emergency vehicles.

Based on the sensor data, the system controls traffic signals, street lights, parking status, and ambulance priority. The phone-controlled car can also be operated remotely.
